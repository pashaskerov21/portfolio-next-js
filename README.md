# Alipasha Askerov — Personal Portfolio

A personal developer portfolio built with **Next.js** and **TypeScript**, featuring interactive 3D elements powered by **Three.js**.

---

## Live Demo

**[alipashaskerov.vercel.app](https://alipashaskerov.vercel.app)**

---

## Portfolio Sections

- **Hero** — Introduction and call-to-action
- **About** — Personal background and skills overview
- **Skills** — Tech stack with visual indicators
- **Experience** — Work history and timeline
- **Projects** — Featured projects with links
- **Contact** — Contact form and social links

## Key Features

- Interactive 3D scene built with Three.js
- App Router with file-based routing
- SSR & SSG for performance and SEO
- Reusable, typed React components
- React Hooks for state and lifecycle management
- ESLint configured for code quality
- Continuous deployment with Vercel
